# Budget AI

API inteligente de gestão financeira desenvolvida com Java, Spring Boot e Spring AI.

O projeto permite registrar receitas e despesas, consultar saldo, listar transações e processar comandos financeiros por meio de um assistente inteligente.

Também foi preparada uma estrutura para processamento de áudio, permitindo o fluxo de transcrição de voz para texto, interpretação da mensagem e geração de resposta em áudio.

---

## Objetivo

Este projeto foi desenvolvido como desafio prático da trilha de Java Back-end com Spring AI da DIO.

A aplicação demonstra a integração entre:

- Spring Boot;
- Spring Data JPA;
- Spring AI;
- Tool Calling;
- banco de dados H2;
- API REST;
- transcrição de áudio;
- Text-to-Speech;
- validação de dados;
- tratamento global de exceções.
